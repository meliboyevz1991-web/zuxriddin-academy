Used To / Be Used To

Used to + V1 oldingi odat yoki hozirgi holatdan farqli vaziyatni bildiradi. Be used to + V-ing/ot esa biror narsaga ko‘nikkanlikni ifodalaydi.

📖 Qoidani tushunib oling

Bolalikdagi odatlar, yangi muhit yoki ish jadvaliga moslashish.

ASOSIY FORMULAused to + V1; didn't use to + V1; be used to + noun/V-ing; get used to + noun/V-ing.
Inglizcha misollar va tarjimasi
I used to live in a village.Ilgari qishloqda yashardim.
She is used to getting up early.U erta turishga ko‘nikkan.
I got used to the weather.Men ob-havoga ko‘nikdim.
💡 Esda tuting: Be used to dan keyin infinitiv emas, -ing shakli keladi.
