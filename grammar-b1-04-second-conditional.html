Second Conditional

Second Conditional hozirgi yoki kelajakdagi xayoliy, haqiqatdan uzoq vaziyatlarni ifodalaydi.

📖 Qoidani tushunib oling

Orzu, maslahat va tasavvur. If I were you iborasi maslahatda keng ishlatiladi.

ASOSIY FORMULAIf + Past Simple, would / could + V1.
Inglizcha misollar va tarjimasi
If I had more time, I'd read more.Vaqtim ko‘proq bo‘lsa, ko‘proq o‘qirdim.
If I were you, I'd rest.Men sening o‘rningda bo‘lsam, dam olardim.
We would travel if tickets were cheaper.Chiptalar arzonroq bo‘lsa, sayohat qilardik.
💡 Esda tuting: If I would have deyish o‘rniga If I had ishlating.
